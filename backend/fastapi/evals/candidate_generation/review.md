# review:判断が必要な内容

投稿が既存のルールと食い違っていて、どちらが正しいか人が判断する必要があるとき。AI はルールを書き換えず、そのルールを人の確認に回す候補(`review`)を作る。

## review-01 現金のみの注意はいらない

- ルール:`rule_008`「現金のみのお店もあります。」
- 投稿:「山之口商店街のお店はほとんどキャッシュレスに対応しているので、現金のみの注意はもういらないと思う。」
- 期待:ルールはもういらないという意見。本当か分からないので、人の確認に回す(review)。「ほとんど」を英訳で「すべてのお店(all shops)」に広げない。

```json
{
  "post": {"text": "山之口商店街のお店はほとんどキャッシュレスに対応しているので、現金のみの注意はもういらないと思う。", "region": "sakai"},
  "expected": {
    "candidates": [{"type": "review", "target_rule_id": "rule_008", "keep": ["山之口商店街", "ほとんどキャッシュレス"], "must_not_add": ["すべてのお店(all shops)", "現金は使えない(cash not accepted)"]}],
    "duplicates": []
  }
}
```

## review-07 重複と食い違いが混ざった投稿

- ルール:`rule_003`「芝生広場にゴミを残さないでください。」
- ルール:`rule_004`「町にゴミ箱はほとんどありません。ゴミは持ち帰ってください。」
- 投稿:「ゴミは持ち帰ってください。それと、芝生広場はゴミを置いていっても清掃の人が片付けるので問題ありません。」
- 期待:前半は `rule_004` と同じなので重複として返し、後半は `rule_003` と食い違うので人の確認に回す(review)。同じ内容を両方に入れない。

```json
{
  "post": {"text": "ゴミは持ち帰ってください。それと、芝生広場はゴミを置いていっても清掃の人が片付けるので問題ありません。", "region": "sakai"},
  "expected": {
    "candidates": [{"type": "review", "target_rule_id": "rule_003", "keep": ["芝生広場", "清掃の人が片付ける"], "must_not_add": ["どこに置いてもよい"]}],
    "duplicates": [{"source": "rule", "id": "rule_004"}]
  }
}
```
